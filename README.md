# А-тур / a-deti — PHP

Исходники PHP-сайта «А-тур», размещённого на https://a-tur.gdesite.ru.

## Версия и состав

Код взят из `sites/a-deti` репозитория `hitechinvest/sitegen`, коммит `eb759082e94f57937621e6c4b249d510c1268973`. Этот выпуск указан в публичной отметке боевого сайта от 13 ноября 2026 года. На момент переноса код этого каталога совпадал с актуальным `master`. Происхождение зафиксировано в `SOURCE.json`.

В корне теперь PHP-проект. Исходники и конфигурация прежнего Next.js-приложения удалены из текущей версии; прежние коммиты доступны в истории Git.

- `index.php` — маршрутизация страниц.
- `inc/` — страницы, каталог, формы, схема БД и админка.
- `site-admin.php` — администрирование содержимого.
- `media.php` — изображения и документы из БД.
- `assets/`, `images/` — оформление, скрипты, шрифты и фотографии выпуска.
- `uploads/` — все 463 публичных файла из прежнего `public/uploads`, включая фотографии и PDF. Пути сохранены.
- `data/seed.json` — исходное наполнение для новой базы.
- `theme.css` и, при наличии, `assets/sitegen-overrides.css` — публичные стили действующего сайта на момент переноса.

## Что эта копия не содержит

Это исходники установленного выпуска, а не побайтный экспорт рабочего каталога сервера. Индивидуальные правки через редактор, отсутствующие в исходном репозитории, могут отличаться.

Текущая база данных боевого сайта, заявки, платежи, подписчики, учётные записи, пароли, ключи API и реальные конфиги не переносились. `data/seed.json` не заменяет резервную копию актуального содержимого БД. Сохранены исходные публичные материалы; исторические отсутствующие вложения не восстанавливались.

## Развёртывание

В репозитории есть `Dockerfile` и `compose.yaml`: PHP 8.4 / Apache, MariaDB 11.4, HTTPS-прокси Caddy. Нужны Docker Engine с Compose plugin либо Docker Desktop. Node.js, Next.js, Prisma и PostgreSQL для работы сайта не используются.

Новая локальная установка:

```bash
git clone https://github.com/AndreyShelemetev/a-deti.git
cd a-deti
bash ops/setup.sh --local
bash ops/install.sh --seed
docker compose run --rm app php bin/console.php admin:create --login=admin
```

Последняя команда предложит ввести новый пароль без отображения. Публичного пароля по умолчанию нет. Сайт: http://127.0.0.1:8080/; админка: http://127.0.0.1:8080/site-admin. Локальные секреты создаются случайно и не попадают в Git. Повторный вызов создания администратора сохраняет существующие учётные записи.

Для переноса **актуальной** базы вместо `ops/install.sh --seed` выполните:

```bash
bash ops/install.sh --import /absolute/path/database.sql.gz
```

Импорт разрешён только в пустую базу. Скрипт переносит таблицы, включая заявки, администраторов и двоичные файлы `media`, затем обновляет структуру без подмены содержимого исходным наполнением. Поддерживаются `.sql` и `.sql.gz` одной базы, без `CREATE DATABASE` и `USE` другого имени. Для дампов MySQL другой версии сначала проверьте совместимость SQL и collations с MariaDB 11.4 на отдельной копии.

Резервная копия и проверка готовности:

```bash
bash ops/backup.sh
docker compose run --rm app php bin/console.php status
```

Данные MariaDB и сессии хранятся в постоянных томах. Файлы `uploads/` входят в образ, новые файлы админки сохраняются в таблице `media`. Обычное обновление не запускает seed и не импортирует SQL. Не удаляйте тома командой `docker compose down -v` при обновлении.

Для сервера с доменом используйте `bash ops/setup.sh --site example.org --email admin@example.org` при первоначальной настройке и `docker compose --profile https up -d --wait` после установки базы. Порты 80/443 должны быть доступны, DNS домена должен указывать на сервер. [Порядок переноса, резервного копирования и настройки GitHub Actions](docs/deployment.md).

CI собирает образ и проверяет свежую установку, вход в админку, доступ к страницам, сохранение данных при миграции, backup/restore с двоичными файлами и перезапуск контейнеров. Публикация образа запускается после успешной проверки `main`; автодоставка на сервер включается отдельно, когда сервер будет выбран.

При установке без Docker нужны PHP 8.4 с PDO MySQL, mbstring, GD, DOM и MySQL/MariaDB. Подключайте `inc/standalone/bootstrap.php` через `auto_prepend_file`, задайте `AT_STANDALONE=1`, `AT_DB_DSN`, `AT_DB_USER`, `AT_DB_PASSWORD` (либо `AT_DB_PASSWORD_FILE`) и выполните `php bin/console.php init --seed` или импорт и `migrate`. Закройте веб-доступ к `inc/`, `data/`, конфигам, SQL и служебным каталогам по образцу `docker/apache.conf`.

Интеграции GdeSite и внешние уведомления требуют отдельной настройки. Заявки сохраняются в собственной админке. Онлайн-оплата в исходном выпуске отключена и остаётся отключённой.
