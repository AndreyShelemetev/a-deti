# А-тур — сайт туроператора по детскому отдыху

Современная реализация сайта [a-deti.ru](https://a-deti.ru) (ранее — 1С-Битрикс): каталог детских лагерей, спортивных сборов, экскурсий и трансферов с онлайн-заявками, оплатой и панелью управления.

Контент исходного сайта (43 актуальных тура, 27 новостей, 30 статей, информационные страницы, 50 SEO-страниц каталога, отзывы, партнёры, фотографии) перенесён в базу данных и доступен для редактирования в админке. Все старые адреса страниц сохранены, для удалённых страниц настроены редиректы 301.

## Стек

| Слой | Технология | Зачем |
|------|-----------|-------|
| Frontend + Backend | **Next.js 16** (App Router, React 19, TypeScript) | SSR для SEO, Server Actions для форм, единый деплой |
| База данных | **PostgreSQL 16** + **Prisma 7** | Типобезопасная схема, миграции, сиды |
| Стили | **Tailwind CSS 4** + дизайн-токены | Яркая, дружелюбная тема, mobile-first |
| Формы и валидация | Server Actions + **Zod** | Единая валидация на сервере, защита от спама (honeypot) |
| Авторизация админки | **jose** (JWT в httpOnly cookie) + bcrypt | Без внешних сервисов, проверка в `proxy.ts` и в каждом действии |
| Изображения | `next/image` + **sharp** | AVIF/WebP, адаптивные размеры, загрузка через админку |
| Почта | **nodemailer** (опционально) | Уведомления о заявках на почту менеджеров |
| Тесты | **Vitest**, Playwright-скрипты | Юнит-тесты утилит/валидации, smoke-тест админки |
| Инфраструктура | Docker, docker-compose, GitHub Actions | Локальный запуск и деплой в один шаг |

Почему единое Next.js-приложение, а не отдельный API-сервер: сайт — контентный, с десятками страниц и несколькими формами. Next.js закрывает и рендеринг (SEO), и серверную логику (Server Actions + Route Handlers), и админку. Для будущих интеграций (мобильное приложение, кабинет агентств) уже есть публичный REST-слой `/api/v1/*`, который можно вынести в отдельный сервис без переписывания фронтенда.

## Функционал

**Публичная часть**
- Главная: слайдер, хиты продаж, лучшие предложения (Россия / за границей), новости, «Коротко о нас», отзывы с рейтингами Яндекс/Google, партнёры, карта, форма заявки.
- Каталог `/tour/` с фильтром по типу, региону, характеристике, возрасту, сезону и поиском; сортировка; пагинация.
- SEO-страницы каталога `/tour/filter/<путь>/` (50 посадочных, как на старом сайте) с редактируемыми H1/title/description и SEO-текстом.
- Карточка тура: галерея с лайтбоксом, смены и цены (с группами — корпуса/дружины), вкладки (описание, проживание, программа, стоимость, документы, противопоказания, отзывы), похожие туры, JSON-LD `Product`.
- Бронирование смены, заказ звонка, общая заявка, подписка на новости, отзыв (модерируется), запрос доступа для агентств.
- Онлайн-оплата по номеру договора (`/pay/`, `/pay/cashback/`) — заявка сохраняется, при настроенном шлюзе посетитель перенаправляется на оплату.
- Новости `/novosti/`, статьи `/stati/`, информационные страницы (родителям, агентствам, трансфер, контакты, политика и т.д.), поиск по сайту.
- SEO: canonical, Open Graph, `sitemap.xml`, `robots.txt`, JSON-LD (Organization, BreadcrumbList, Product, NewsArticle), сохранение старых URL с trailing slash, редиректы для `/news/*.html`, `*.php` и архивных туров, Яндекс.Метрика.

**Панель управления `/admin/`** (роли: администратор, менеджер)
- Заявки: список с фильтрами по типу и статусу, карточка, статус и комментарий.
- Туры: полный редактор (смены/цены, галерея с загрузкой, вкладки в HTML-редакторе, характеристики, документы, SEO, публикация, флаги «лучшее»/«хит»).
- Страницы каталога (SEO-посадочные) с правилами отбора туров; характеристики и регионы.
- Новости и статьи, текстовые страницы (новые страницы открываются по `/slug/` без правки кода).
- Главная: слайдер, хиты, «Коротко о нас», партнёры, рейтинги площадок.
- Отзывы с модерацией, платежи, подписчики, настройки сайта (контакты, реквизиты, соцсети, SEO главной), пользователи.

## Быстрый старт

```bash
cp .env.example .env            # заполните DATABASE_URL и AUTH_SECRET
pnpm install                    # генерирует Prisma Client (postinstall)
pnpm db:migrate                 # применяет миграции (нужен PostgreSQL)
pnpm db:seed                    # загружает контент a-deti.ru и создаёт админа
pnpm dev                        # http://localhost:3000
```

Админка: `http://localhost:3000/admin/` — логин/пароль из `ADMIN_EMAIL` / `ADMIN_PASSWORD` в `.env` (по умолчанию `admin@a-deti.ru` / `admin12345` — смените перед деплоем).

Через Docker:

```bash
docker compose up --build       # Postgres + приложение на :3000, миграции применяются при старте
docker compose exec web ./node_modules/.bin/prisma db seed   # первичное наполнение
```

  components/            — UI (ui/, layout/, tour/, home/, forms/, admin/)

## Модель данных (кратко)

- `Tour` — тур/лагерь: тип (`CAMP | FAMILY | SPORT | EXCURSION | TRANSFER | YOUTH`), регион, сезоны, возраст, цена, SEO, флаги. Связи: `TourShift` (смены и цены, группы), `TourImage`, `TourSection` (вкладки), `TourTag`, `TourDocument`.
- `Tag` (характеристики) и `Region` — справочники фильтра, у тегов есть собственные SEO-поля для `/tour/filter/<slug>/`.
- `CatalogPage` — SEO-посадочная каталога: путь + правило (тип, регионы, теги, сезон) + тексты.
- `Post` (`NEWS | ARTICLE`), `Page` — контент; `Slide`, `Feature`, `Partner`, `ReviewPlatform`, `Review` — блоки главной.
- `Request` — все заявки (`REQUEST | CALLBACK | BOOKING | SUBSCRIBE | AGENCY | REVIEW`), `Payment`, `Subscriber`.
- `User`, `Setting` (ключ/значение), `Redirect` (старые адреса).

## SEO и миграция с Битрикса

- Адреса страниц сохранены 1:1 (`/tour/<slug>/`, `/tour/filter/…/`, `/novosti/<slug>/`, `/stati/<slug>/`, `/rodytelyam/` и т.д.), включая завершающий слэш (`trailingSlash: true`).
- Редиректы 301/308: `/news/<slug>.html → /novosti/<slug>/`, `/personal_data.php → /personal-data/`, `/pay/cacheback.php → /pay/cashback/`, старые smart-filter URL `/tour/filter/type-is-…/` → `/tour/`, 37 архивных туров → `/tour/`. Список редиректов редактируется в таблице `Redirect`.
- `title`/`description`/`H1` перенесены; шаблон `{year}` подставляет текущий год (как на старом сайте).
- Страницы с параметрами (`?page=`, `?sort=`, фильтры) помечены `noindex`, SEO-посадочные — `index`.
- После запуска: добавить сайт в Яндекс.Вебмастер / Search Console, указать `NEXT_PUBLIC_SITE_URL`, проверить `sitemap.xml`.

## Что осталось подключить

- **Эквайринг Сбербанка**: заполнить `PAYMENT_GATEWAY_*` и реализовать callback (`src/server/actions/payments.ts` — точка расширения; статусы платежей уже есть в админке).
- **SMTP** для уведомлений о заявках (`SMTP_*`, `LEADS_EMAIL`); без него заявки просто копятся в админке.
- **Яндекс.Метрика**: `NEXT_PUBLIC_YANDEX_METRIKA_ID` (счётчик старого сайта — 104199506).
- Фотографии: перенесено по обложке + до 8 фото на тур (всего 464 файла, WebP). Остальные фото галерей можно догрузить через админку или повторным импортом (`scripts/convert-images.mjs`).
- Кабинет агентств (на старом сайте — только форма входа): заявки агентств уже собираются, авторизация агентств — следующий шаг.
